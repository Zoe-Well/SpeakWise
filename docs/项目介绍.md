# SpeakWise — 智能面试助手

> 更新时间：2026-07-27

## 项目概述

SpeakWise 是一个桌面端 AI 面试助手。它将用户当前选中的简历、岗位 JD 和附件素材组织成受预算控制的上下文，再根据会话模式和用户意图选择对应提示词，提供面试问答、自我介绍、场景题、技术题、模拟面试和简历评审。

项目更准确的定位是：**领域 Copilot + 确定性工作流**。当前没有向量检索、ReAct 循环或模型自主工具调用。

## 核心技术点

### 1. 统一上下文构建

`ContextBuilder` 统一加载并格式化：

- 结构化简历：实习、项目、技能；
- 当前活跃 JD：核心技能、职责、价值观；
- 用户选中的个人和公司附件；
- 会话滚动摘要与最近消息。

上下文采用独立字符预算：简历 6,000、JD 2,500、个人附件 5,000、JD 附件 3,000、历史摘要 2,000、最近消息 6,000。这样可以控制输入规模，也避免同一附件或历史被重复注入。

### 2. 意图与模型路由

面试模式采用混合意图路由：

- `/intro`：自我介绍；
- `/scenario`：STAR 场景题；
- `/technical`：技术题；
- `/followup`：模拟追问；
- 无明确分类：通用面试辅导。

显式命令优先；高置信度问题由加权规则直接分类；短追问继承最近题型；低置信或规则冲突时才调用快速模型分类。普通模式下，面试相关问题使用主模型，其他问题使用与当前 Provider 兼容的快速模型。

### 3. 会话与记忆

- 会话默认模式统一为 `normal`，可在普通和面试模式间切换；
- JD 统一使用当前简历下的全局活跃 JD；
- 最近 8 条消息保留原文；
- 更早的消息由快速模型生成滚动摘要，保存到 SQLite；
- 简历、项目、技能、附件和模板作为可编辑的长期知识记忆。

### 4. 流式与可靠性

后端通过 SSE 分别发送：

- `thinking`：模型 reasoning；
- `token`：回答正文；
- `done/error`：完成或脱敏错误。

统一 `GenerationGuard` 为对话、模拟面试、评审、JD 和简历解析提供会话归属校验、并发互斥和频率限制。全局 semaphore 覆盖完整模型流，最多同时处理 3 个 LLM 流式调用。

## 主要功能

- 多简历及结构化经历管理；
- 多 JD 解析、激活与切换；
- PDF、DOCX、TXT 附件导入；
- 普通对话与面试辅导模式；
- 自我介绍、STAR 场景题、技术题和追问；
- 模拟面试、回答评审与面试总结；
- 简历评审和岗位匹配分析；
- Prompt 模板与默认模板管理；
- DeepSeek reasoning 流式展示；
- 讯飞语音输入；
- Electron 透明置顶提词器。

| 层 | 技术 |

| 桌面端 | Electron 43 |
| LLM | DeepSeek 主模型 + OpenAI 兼容接口 |

## 架构取舍

当前知识库规模以个人简历和少量岗位资料为主，因此采用 SQL 查询和确定性上下文注入，没有引入向量数据库。这让系统更轻量、可解释；如果未来附件规模明显增长，再引入切块、Embedding 和 Top-K 检索。
