# SpeakWise — AI面试教练

## 一句话概括

一个**多模型、多知识源的 RAG 对话应用**——自动将用户的简历、岗位JD、附件文档注入 LLM System Prompt，根据意图动态选择提示词模板和模型，实现个性化面试辅导。支持 DeepSeek / GPT / Claude 三模型热切换、多简历管理、模拟面试、简历评审、讯飞语音实时输入、Electron 桌面提词器。

## 从 AI 应用开发角度看三个亮点

**1. 知识库注入管线不是简单的字符串拼接**

`build_profile_data_for_prompt()` 从 SQLite 加载 6 张表的数据——结构化简历字段（姓名/技能/项目）、JD 解析的关键词（core_skills/duties/culture_values）、以及 `SourceDocument` 表中原始文档文本（提取后截断到 3000 字）。这些数据经过模板系统格式化后注入到不同 scope 的 System Prompt 中，而不是简单地 `f"用户简历：{resume}"`。每条知识源都有独立的截断策略和优先级。

**2. 意图识别 + 动态 Prompt 路由**

`classify_interview_intent()` 用关键词打分法判断用户输入属于自我介绍、场景行为题还是技术题——三种类型走三套不同的 System Prompt，每套都有独立的模板默认值。这不是简单的 if-else，而是一个 **轻量级意图路由器**：不需要额外的分类模型调用，零延迟，在用户打字的同时就完成了路由决策。

**3. LLM 配置拦截 + 全局 ApiKey/模板管理**

所有依赖 LLM 的功能（对话/简历解析/JD分析/模拟面试/简历审阅/文档素材上传）在 LLM 未配置时都会被**前端前置拦截**——弹出引导弹窗，点击直接跳转设置页并高亮对应区域。ApiKey 和提示词模板改为全局管理（不绑定单份简历），切换简历不影响已配置的 Key 和模板。ApiKey 支持去重校验、添加/切换时强制验证有效性、失效 Key 拒绝激活。

## 技术栈

| 层 | 技术 | 选型理由 |
|------|------|----------|
| 前端 | React 18 + Vite + Tailwind CSS + TanStack Query | 组件化 + 原子化CSS + 构建快 + 服务端状态管理 |
| 桌面 | Electron 32 | 透明置顶悬浮窗(浏览器做不到) |
| 后端 | Python FastAPI + SQLModel | 异步原生支持 + ORM + LLM SDK生态 |
| 数据库 | SQLite | 零配置，单文件，桌面应用标配 |
| LLM | DeepSeek V4 Pro (主) + OpenAI + Anthropic | 多provider热切换 |
| 语音 | 讯飞语音听写 WebSocket API | 国内中文识别精度最高 |
| 流式 | SSE (Server-Sent Events) | 单向数据流，比WebSocket轻量 |

## 核心功能模块

- **多简历管理**：支持创建多份简历，每份独立管理实习/项目/技能数据。新建简历自动激活，切换简历自动刷新全量数据
- **知识库**：简历CRUD + 附件文档上传/解析(LLM提取结构化字段) + 文档原文注入Prompt。支持追加/替换两种导入模式，解析失败可重新解析
- **JD分析**：LLM解析岗位描述→提取core_skills/duties/culture_values→支持多JD管理/切换
- **对话引擎**：4种Slash命令(/intro/scenario/technical/followup) + 面试模式自动意图识别。对话页顶部知识选择栏可实时切换简历/JD/素材
- **模拟面试**：AI面试官多轮对话——开始提问→用户回答→AI评估/追问/跳过→下一题→面试汇总，支持会话管理
- **简历评审**：AI深度评审简历亮点/风险/改进建议，支持岗位匹配度分析
- **模板系统**：三类Prompt模板(自我介绍/STAR/技术题) + 用户自定义 + Scope级默认值。全局共享，不受简历切换影响
- **模型路由**：面试话题→Pro模型(deepseek-v4-pro) / 非面试→Fast模型(deepseek-chat) + 用户可切换provider
- **思考链可视化**：DeepSeek reasoning_content实时流式展示，可折叠
- **语音输入**：AudioWorklet 16000Hz PCM采集 → 浏览器WebSocket直连讯飞（JSON Base64编码）→ 实时转写。未配置时弹窗引导
- **LLM配置拦截**：所有LLM依赖功能统一前置检查——未配置API Key时弹窗拦截并引导跳转，设置页对应区域金色高亮
- **提词器**：Electron透明悬浮窗，半透明置顶，自动滚屏，字号/透明度可调
- **打包分发**：PyInstaller后端 + Electron-Builder前端，单文件夹免安装
