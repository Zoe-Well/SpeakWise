# SpeakWise Portfolio README Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为 SpeakWise 创建中文为主的作品集型 GitHub README，包含两张真实界面截图，并推送到当前 GitHub 仓库。

**Architecture:** README 作为单一项目入口，使用相对路径引用 `docs/images/` 下的两张 PNG 截图。内容只描述当前代码和已验证能力；截图从本地运行中的应用生成并裁剪到核心区域，避免暴露联系方式、API Key 或终端信息。

**Tech Stack:** Markdown、Mermaid、PNG、Git、GitHub

## Global Constraints

- 中文为主，技术名词保留通用英文名称。
- 定位为个人作品集展示，首要受众是招聘方、面试官和技术负责人。
- 包含 AI 对话页、个人知识库与技术栈分类页两张真实截图。
- 截图不得暴露 API Key、环境变量、终端内容、手机号或邮箱。
- 启动命令与当前仓库一致：前端端口 5173、后端端口 8001、Electron 入口为根目录 `main.js`。
- 不宣称云端服务、多人协作、认证或其他尚未实现的能力。
- 不新增依赖，不修改产品代码，不提交用户原有未跟踪的 `AGENTS.md`。

### Task 2: 编写作品集型 README

**Files:**

- Modify: `README.md`

**Interfaces:**

- Consumes: `docs/images/speakwise-conversation.png`、`docs/images/speakwise-profile-skills.png`
- Produces: GitHub 仓库首页文档

- [ ] **Step 1: 记录当前 README 验证失败**

Run:

```powershell
$readme = Get-Content -Raw README.md
@('# SpeakWise', '## 项目亮点', '## 快速开始', 'docs/images/speakwise-conversation.png') |
  ForEach-Object { if (-not $readme.Contains($_)) { Write-Output "MISSING: $_" } }
```

Expected: 输出至少一个 `MISSING`，因为当前 README 为空。

- [ ] **Step 2: 编写 README**

README 按以下顺序编写，避免重复内容：

```text
标题与一句话定位
项目截图
项目亮点
主要功能
系统架构（Mermaid）
技术栈
快速开始
环境配置
测试与质量保障
项目结构
当前状态与后续方向
仓库链接
```

快速开始必须包含：

```powershell

cd frontend
npm install
npm run dev
uv run uvicorn backend.src.main:app --host 127.0.0.1 --port 8001 --reload
$env:NODE_ENV="development"; npx electron .
```

测试命令必须包含：

```powershell
uv run pytest backend/tests -q
cd frontend
npm test
npm run build
```

- [ ] **Step 3: 验证 README 内容和引用**

Run:

```powershell
$readme = Get-Content -Raw README.md
$required = @('# SpeakWise', '## 项目亮点', '## 主要功能', '## 系统架构', '## 快速开始', '## 测试与质量保障', 'docs/images/speakwise-conversation.png', 'docs/images/speakwise-profile-skills.png')
```

### Task 3: 验证并推送到 GitHub

**Files:**

- Verify only

**Interfaces:**

- Consumes: 当前 `main` 分支提交和 `origin`
- Produces: GitHub 上更新后的 SpeakWise 仓库首页

- [ ] **Step 1: 核对提交和工作区**

Run:

```powershell
git status --short
git log -3 --oneline
git remote -v
```

Expected: 除用户原有未跟踪 `AGENTS.md` 外无未提交变更；`origin` 指向 `https://github.com/Zoe-Well/SpeakWise.git`。

- [ ] **Step 2: 推送当前 main**

Run:

```powershell
git push origin main
```

Expected: exit code 0，远程 `main` 更新到本地最新提交。

- [ ] **Step 3: 验证远程提交**

Run:

```powershell
$local = git rev-parse HEAD
$remote = git ls-remote origin refs/heads/main | ForEach-Object { ($_ -split "`t")[0] }
if ($local -ne $remote) { throw "远程 main 未同步" }
```

Expected: exit code 0，本地 HEAD 与远程 `main` SHA 一致。
