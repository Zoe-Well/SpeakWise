# SpeakWise README 设计说明

## 目标

为 SpeakWise 编写一份中文为主、面向个人作品集展示的 GitHub README。文档应让招聘方或面试官快速理解项目解决的问题、核心能力、技术深度和本地运行方式，同时保持开发者可以实际复现。

## 受众

- 首要受众：招聘方、面试官和技术负责人。
- 次要受众：希望本地体验或阅读源码的开发者。

## 内容结构

1. 项目标题与一句话定位。
2. 两张真实界面截图：AI 对话页、个人知识库与技术栈分类页。
3. 核心亮点：个性化知识库、SSE 流式对话、跨页面任务保留、技术栈智能分类、面试提词器。
4. 产品功能概览。
5. 简洁的系统架构图。
6. 前端、后端、桌面端和 LLM 技术栈。
7. 可执行的快速开始与环境配置。
8. 测试与质量保障说明。
9. 精简项目结构。
10. 当前状态、后续方向和仓库链接。

## 截图方案

- 截图保存到 `docs/images/` 并由 README 使用相对路径引用。
- 第一张展示 AI 对话主界面和知识库选择能力。
- 第二张展示个人知识库的技术栈固定分类与“AI 智能整理”入口。
- 截图不得暴露 API Key、环境变量、终端内容或其他密钥。
- 可保留测试简历中的普通项目数据，但避免突出手机号、邮箱等个人联系方式；必要时裁剪到核心区域。

## 写作原则

- 中文为主，技术名词保留通用英文名称。
- 以项目价值和真实实现为主，不使用无法验证的性能数字或营销口号。
- 启动命令必须与当前仓库入口一致：前端 5173、后端 8001、Electron 根目录入口。
- 不宣称云端服务、多人协作、认证或其他尚未实现的能力。
- 不复制大段内部规格，只呈现 GitHub 首页需要的信息。

## 验证与发布

- 核对 README 中引用的本地文件和截图路径存在。
- 核对安装、启动、测试命令与项目配置一致。
- 检查 README 和截图不包含 API Key 等敏感信息。
- 提交 README、设计说明和截图后推送到当前 `origin` 的 `main` 分支。
